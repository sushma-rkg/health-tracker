# Design reference

Four screenshots of the approved look (laptop layout). Every build step looks at these together with `design-notes.md`.

- `body.webp` – the Body page
- `mind.webp` – the Mind page
- `reports.webp` – the Reports page
- `settings.webp` – the Settings page

Use them for **style only**: colours, fonts, shapes, spacing and how things are laid out.
They also show things that are NOT in my approved data plan (for example headache, energy, anxiety, daily notes, medicine dose lists). Do not build those. What each page holds is listed in `design-notes.md`.
